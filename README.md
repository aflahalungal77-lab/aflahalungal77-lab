## About

I'm **Muhammed Aflah Alungal**, a student developer from **Malappuram, Kerala, India**.

I build full-stack web applications and enjoy turning ideas into working products. My web development work includes responsive interfaces, backend APIs, authentication flows, databases, and applications built with the MERN stack and Next.js.

I'm now focusing more deeply on **Artificial Intelligence and Machine Learning**. I'm learning the fundamentals by writing code, running experiments, understanding the underlying concepts, and building small projects before turning them into larger applications.

I use AI coding tools as assistants, while making an effort to understand, test, and review the code behind the projects I build.

I'm also the **Co-Founder & Associate Director of Z Alpha Thinkers Community**, a community for young builders, developers, and technology enthusiasts.
