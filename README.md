## ✦ A little about me

I'm **Muhammed Aflah Alungal**, a student developer from **Malappuram, Kerala, India**.

I enjoy building useful digital products and learning how the systems behind them work. My experience so far is centred on full-stack web development — creating interfaces, connecting APIs, working with databases, and shaping ideas into usable applications.

My focus is now moving deeper into **Artificial Intelligence and Machine Learning**. I'm studying the fundamentals through hands-on coding, small experiments, and projects — not just using tools, but understanding what happens behind the scenes.

I use AI tools as part of my workflow, while working to understand, test, and review the code they help me create.
